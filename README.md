# HM-T²: HMM-Enhanced T² 

MATLAB implementation of the HMM-enhanced T² (HM-T²) monitoring method used with Mahalanobis distance (MD) on the Tennessee Eastman process.

Companion paper:

> **Prior Probability Can Enhance Hotelling's T-square Index to Improve Process Monitoring Performance**  
> Tongze Hou, Xin Ma, Haotian Zhang, and Youqing Wang

## Overview

HM-T² augments a conventional T² monitoring statistic with state-transition information. The normal operating region is divided into several substates, and an additional HMM state represents the faulty condition. At each sampling instant, the current T² observation and its history are used for Viterbi inference. The HM-T² index compares the current fault-state score with the most probable normal-substate score.

The demo is written as a sample-by-sample stream:

```text
new process sample x_k
        |
        v
       MD
        |
        v
      T^2_k  ---> append to T^2 history
                         |
                         v
                    HMT2_Test
                         |
                         v
                state_k and HM-T^2_k
```

## Pseudocode

The following pseudocode reproduces Algorithms 1 and 2 from the companion paper, with mathematical notation adapted to plain text. Equation numbers refer to the paper. Algorithm 2 describes the paper's hyperparameter-selection procedure; the demo uses the supplied parameter files rather than repeating this procedure.

### Algorithm 1: Fault detection based on HM-T²

```text
Input: HMM model parameters H = (A, B, pi),
       number of normal substates m.
Initialize an empty vector Z.

loop
    For a real-time measured sample x_t, compute T²_t using
    a predefined algorithm such as PCA or CCA.
    Calculate the observation o_k corresponding to T²_t.
    Update the normal-to-fault transition probability
    using Eqs. (26) and (28).
    Z <- [Z, o_k].
    Use the Viterbi algorithm to compute the prior probabilities
    and state index: i*_t <- Viterbi(H, Z).
    If HM-T² > 1 (equivalent to i*_t = m + 1), report faulty;
    otherwise, report normal.
    if length(Z) > L* then
        Reset Z to an empty vector.
    end if
end loop
```

Here, `L*` is the preset observation-sequence length threshold. Apply the transition probability update (TPU) only when its applicability conditions in the paper are satisfied.

### Algorithm 2: Configuring the Hyperparameters

```text
Input: Candidate sets U for u and M for m,
       HMM model parameters H = (A, B, pi),
       training-phase observation sequence Z_train.
Initialize g = 0, theta = 0, l = 0.
Add noise to the index at intervals of several samples
until it exceeds the chi-squared control limit chi²_varsigma(v).

for m in M do
    theta <- theta + 1.
    for u in U do
        l <- l + 1.
        for o in Z_train do
            Compute the state index i*_t corresponding to o.
            if i*_t = m + 1 then
                g <- g + 1.
            end if
        end for
        FAR(theta, l) <- g / length(Z_train).
        g <- 0.
    end for
end for

Determine P*, the set of all (m, u) pairs minimizing FAR.
Select m as the largest m among the pairs in P*.
Select u as the smallest u among the pairs in P* with this m.
Output: m, u.
```

## Quick start

Run:

```matlab
demo_Mahalanobis_distance
```

The default example uses TE fault IDV(9).

## Main files

- `demo_Mahalanobis_distance.m` — sample-by-sample TE monitoring demo.
- `MD.m` — MD/T² model training and online evaluation.
- `HMT2_train.m` — construction of the HMM transition and emission matrices.
- `HMT2_Test.m` — batch and online HM-T² inference.
- `hmmviterbi0.m` — Viterbi decoding used by HM-T².
- `Monte_Carlo.m`, `Monte_Carlo2.m` — Monte Carlo evaluation of fault-state emission probabilities.
- `transition.m` — empirical transition-matrix estimation.
- `my_adftest.m` — lightweight stationarity pre-check used by the demo.
- `te/` — Tennessee Eastman data used in the example.

## Parameters

The repository includes the parameter files used by the demo:

- `slice_op.mat` — number of normal substates.
- `u_op.mat` — emission-probability smoothing parameter.
- `A.mat` — HMM transition matrix.
- `B.mat` — HMM emission matrix.

If `A.mat` and `B.mat` are removed, they are regenerated by `HMT2_train.m` from the supplied `slice_op` and `u_op`. Selection of `slice_op` and `u_op` follows the parameter-selection procedure described in the paper and is not repeated in this demo.
