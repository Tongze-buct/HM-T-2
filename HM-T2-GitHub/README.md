# HM-T²: HMM-Enhanced T² 

MATLAB implementation of the HMM-enhanced T² (HM-T²) monitoring method used with Mahalanobis distance (MD) on the Tennessee Eastman process.

Companion paper:

> **Prior Probability Can Enhance Hotelling's T-square Index to Improve Process Monitoring Performance**  
> Tongze Hou, Xin Ma, Haotian Zhang, and Youqing Wang

## Overview

HM-T² augments a conventional T² monitoring statistic with state-transition information. The normal operating region is divided into several substates, and an additional HMM state represents the faulty condition. At each sampling instant, the current T² observation and its history are used for Viterbi inference. The HM-T² index compares the current fault-state score with the most probable normal-substate score.

The demo is written as a sample-by-sample stream:

```text
new process sample x_k
        |
        v
       MD
        |
        v
      T^2_k  ---> append to T^2 history
                         |
                         v
                    HMT2_Test
                         |
                         v
                state_k and HM-T^2_k
```

## Quick start

Run:

```matlab
demo_Mahalanobis_distance
```

The default example uses TE fault IDV(9).

## Main files

- `demo_Mahalanobis_distance.m` — sample-by-sample TE monitoring demo.
- `MD.m` — MD/T² model training and online evaluation.
- `HMT2_train.m` — construction of the HMM transition and emission matrices.
- `HMT2_Test.m` — batch and online HM-T² inference.
- `hmmviterbi0.m` — Viterbi decoding used by HM-T².
- `Monte_Carlo.m`, `Monte_Carlo2.m` — Monte Carlo evaluation of fault-state emission probabilities.
- `transition.m` — empirical transition-matrix estimation.
- `my_adftest.m` — lightweight stationarity pre-check used by the demo.
- `te/` — Tennessee Eastman data used in the example.

## Parameters

The repository includes the parameter files used by the demo:

- `slice_op.mat` — number of normal substates.
- `u_op.mat` — emission-probability smoothing parameter.
- `A.mat` — HMM transition matrix.
- `B.mat` — HMM emission matrix.

If `A.mat` and `B.mat` are removed, they are regenerated by `HMT2_train.m` from the supplied `slice_op` and `u_op`. Selection of `slice_op` and `u_op` follows the parameter-selection procedure described in the paper and is not repeated in this demo.
